# 数学I・IIラボ

数学I・数学IIを、**グラフをさわって・動かして** 学べる Webアプリです。
見た目と使い方は「数学Aラボ」とそろえてあります（方眼ノート風）。

`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで動きます。インストールは いりません。

## 使い方

1. 上のメニューで「数学Ⅰ」「数学Ⅱ」をえらぶ
2. 左の一覧から 単元をえらぶ
3. 右の「📖 授業」で、下の 6 段階を 1 画面ずつ進む（「次へ ▶」は右下に固定。スクロールしなくても押せる）

| 段階 | すること |
|---|---|
| 導入 | 「どこで使う？」と、生活の場面のかんたんな問題で「こういうときは こうする」をつかむ |
| 例題 | 1 ステップずつ 考え方を見る（キーボードの → でも進む）。グラフも いっしょに動く |
| 類題 | 例題と同じ考え方で 自分で解く（数字は毎回かわる） |
| 演習 | 数字が毎回かわる問題。**3 問正解で 合格** |
| 応用B | 生活の中の文章題（ボールの高さ・利益・測量・薬の量・箱の容積 など） |
| 応用C | ちょっとむずかしい問題 |

- 問題は 4 択。まちがえても すぐ答えは出さず、ヒントが出て もう一度えらべます。
- 答えるまで グラフと答えの式は かくれています（スマホでは グラフをたたんで スクロールを へらす）。答えると グラフで たしかめられます。
- 「👆 さわる」：グラフの光る点をドラッグしたり、スライダーを動かしたりして、式とグラフのつながりを見る。
- 一覧の「2/6」は 終わった段階の数。全部終わると「✓ 完了」。次に開くと 続きの段階から始まります。
- 「🎯 まとめ練習」：数学Ⅰ／数学Ⅱ／ぜんぶ から 10 問。最後に点数と、ふくしゅうしたい単元が出ます。
- 「⛶」で グラフを全画面（プロジェクター用）。「あA」で文字の大きさ、「🌗」で明るい／暗い画面。
- URL の最後に `#quad` のように付けると、その単元を開いたリンクになります（`#quad/ex` で例題、`#quad/B` で応用B、`#quad/touch` で さわる から）。
- 進み具合は そのブラウザの中に保存されます。

## 単元

| 数学Ⅰ | | 数学Ⅱ | |
|---|---|---|---|
| `#expand` | 展開と因数分解（面積の図） | `#circle` | 円の方程式 |
| `#quad` | 2次関数のグラフ | `#trigfn` | 三角関数のグラフ（振幅・周期・ラジアン） |
| `#sqc` | 平方完成 | `#exp` | 指数関数・指数法則 |
| `#minmax` | 最大・最小（範囲つき） | `#log` | 対数関数・対数の計算 |
| `#disc` | 2次方程式と判別式 | `#deriv` | 微分と接線 |
| `#ineq` | 2次不等式 | `#kyoku` | 増減と極値 |
| `#trig` | 三角比（半径 1 の円） | `#integ` | 積分と面積 |
| `#tri` | 正弦定理・余弦定理 | | |
| `#data` | データの分析（平均・分散・箱ひげ図） | | |

## ファイル

- `index.html` … 画面と見た目
- `js/plot.js` … グラフ（座標平面）をかく道具
- `js/util.js` … 数の書き方・問題づくりの道具
- `js/units1.js` … 数学Ⅰの単元（さわる・例題・練習問題）
- `js/units2.js` … 数学Ⅱの単元
- `js/lessons.js` … 授業の 導入・応用B・応用C（文章題）と「どこで使う？」
- `js/app.js` … 画面の切りかえ・授業の流れ・まとめ練習
